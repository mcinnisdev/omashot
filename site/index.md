features:
  - title: Bundles an agent can work from
    details: Grab a region, type what is wrong, keep going. The bundle is a folder with a markdown file that reads in order and every screenshot linked relatively. Hand it to a CLI agent as a path or to a chat agent as a ZIP.
  - title: Auto-capture a process
    details: Record a region and get a GIF, an MP4 and a still at every click, each labelled with what happened and where. An agent turns it into a process document with the images in place.
  - title: Studio recordings for people
    details: Record with the cursor hidden, then draw it back in smoothed. Zoom in where the work is, live with one key or afterwards on a timeline. Click ripples, keystroke badges, your camera in a bubble, narration in sync.
  - title: Edit in minutes, export to MP4
    details: Trim, cut the middle out, drag zoom blocks, add a title and your logo. Export renders exactly what you previewed, H.264 with AAC narration, at 720p to 1440p.
  - title: Your brand, not ours
    details: Drop a logo, colours and voice notes into one folder. Bundles carry it to the agent; the studio puts it on the video.
  - title: Lightweight by design
    details: A tray icon, a few hotkeys, a folder of files you can read. No account, no upload, nothing leaves your machine unless you send it.
