# One thing, right now

Most of the time there is no list. There is one thing, on one screen, and the
cost of reporting it is entirely in the describing.

## Do it

<kbd>Super</kbd><kbd>Alt</kbd><kbd>Q</kbd>, drag, type, <kbd>Enter</kbd>.
<kbd>Ctrl</kbd><kbd>Enter</kbd> hands it off:

```
/home/you/Omashot/Quick/2026-09-19_101512/01.png
The save button is clipped at 125% scaling.
```

Paste that into an agent. It has the picture and the sentence, and the sentence
is short because the picture is doing the other half of the work.

## When it turns into three

Keep going. Each shot joins the loose ones, and
<kbd>Ctrl</kbd><kbd>Enter</kbd> on the last copies all of them with their
notes. Then they clear, so the next one starts fresh — an agent is never
pointed at something you already dealt with.

If it turns out to be a real list spanning pages, that is what a
[brief](/use-cases/fix-list) is for.

## Something you already screenshotted

`omashot edit that-screenshot.png` adopts a file that already exists and
opens it for markup and a note.

Point Omarchy's own screenshot key at it and every
<kbd>Super</kbd><kbd>Shift</kbd><kbd>S</kbd> can end the same way — see
[shots](/docs/shots#marking-up-something-you-already-have).
