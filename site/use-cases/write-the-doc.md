# A document that writes itself

You have a brief. Someone wants a document. The gap between those two things
is smaller than it looks: a brief is already sections, in order, with a
sentence under each picture.

**Hand off → Export document** closes it without an agent in the loop.

## What you get

Sections become headings. Notes become numbered steps. Each image sits under
the step it belongs to. The section note becomes the paragraph that introduces
the section.

Two formats:

- **A web page** — one self-contained HTML file with the images inlined.
  Nothing to unzip, nothing to link, no folder to keep alongside it. Send the
  file.
- **Markdown** — beside the images, for a repo, a wiki or anything that
  renders Markdown.

Both land in the brief's own folder.

## With your brand on it

Put a logo, colours and voice notes in `~/Omashot/brand/` and they ride along
— see [brand kit](/docs/brand-kit). The exported page uses them directly; an
agent working from the brief is told to match them.

## When to use an agent instead

Export when the notes are already the words you want. The document is your
sentences, tidied and laid out — it will not invent prose you did not write.

Hand it to an agent when the notes are shorthand and you want them turned into
something a stranger could follow. Set the purpose to *Write process doc* and
the prompt asks for exactly that, with the images referenced by their relative
paths.
